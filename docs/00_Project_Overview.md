# Camcare Simple M1

## Purpose

Camcare Simple M1 is a clinic management system based on an existing
CodeIgniter 3 Hospital Management System.

The objective is NOT to rewrite the application.

The objective is to gradually transform the existing system into a
stable, maintainable and production-ready clinic management system.
